### 👨‍💻 About Me

I'm **Sujan Tamang**, a **Junior Backend Engineer** from Nepal who enjoys building reliable, scalable, and maintainable software.

My primary focus is **backend engineering**, while my full-stack experience allows me to understand and build applications from the database to the user interface.

Currently, I work with **C#/.NET, GraphQL, PostgreSQL, Kafka, Redis, and Entity Framework Core** to build production backend systems.

I also have experience building full-stack applications using the **MERN stack, Next.js, React, and Tailwind CSS**.

I enjoy learning how systems work under the hood, solving problems, and turning ideas into working products. 🚀
